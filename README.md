## 4. Mathematical Model / 数理モデル

交渉決裂確率を算出するため、以下の数理モデルを構築する。
$$P_{breakdown} = \frac{\sum_{i=1}^{n} (D_i \cdot W_i)}{C_{trust} \cdot T_{margin}}$$ 


## 変数定義

* $P_{breakdown}$：交渉決裂確率（$0 \le P_{breakdown} \le 1$）
* $D_i$：各論点 $i$ における米イ間の不一致度（$0 \le D_i \le 1$、完全排他を $1$ とする）
* $W_i$：各論点 $i$ の重要度ウエイト（$\sum W_i = 1$）
* $C_{trust}$：相互信頼および仲介国調整係数（$0 < C_{trust} \le 1$、不信感最大を $1$ とする）
* $T_{margin}$：タイムリミットまでの時間的余裕（停戦延長期間に基づく減衰因子）
